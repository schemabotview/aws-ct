# ADR-007: Run the order API on ECS Fargate, with RDS PostgreSQL Multi-AZ

Status: accepted, 2026-10-20. Owner: alex. Revisit at 5x today's peak.

## Context
Checkout needs PostgreSQL transactions (Course 9). The team knows
containers, not Kubernetes. Patching 6 servers a month costs a day.

## Options (scored in evolve/score_options.py)
- EC2 + RDS: the shape we run now; we patch the OS.
- ECS Fargate + RDS: no servers to patch; same container image.
- Lambda + DynamoDB: no PostgreSQL; rewrites every query. Rejected.
- EKS + RDS: a cluster we have no one to run. Rejected.

## Decision
ECS Fargate for the API, RDS PostgreSQL Multi-AZ unchanged.

## Consequences
+ No OS patching; deploys stay the same image.
- Higher price per vCPU-hour than committed EC2; watched monthly.
